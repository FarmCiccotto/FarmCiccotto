## Getting Started

### Prerequisites
- Node.js (version 14 or higher)
- npm (version 5.6 or higher)

### Installation
To install the dependencies, run:
```bash
npm install
```

### Running the Application
To start the development server, run:
```bash
npm start
```

### Building for Production
To create a production build, run:
```bash
npm run build
```
